Install in a minute

Three quick steps.

Daily Streaks isn't on Google Play yet, so you install it directly. It's the same signed app.

  1. 1

    Download

    Tap Download for Android on your phone. The file is called DailyStreaks-1.3.0.apk.

  2. 2

    Allow the install

    Open it from Files → Downloads. If Android asks, allow installs from that app. If Play Protect warns you, tap More details → Install anyway.

  3. 3

    Start a streak

    Open Daily Streaks, pick a few starter habits, and check off your first one today.

Questions

Good to know.

Is it really free?

Yes. No subscription, no in-app purchases and no ads.

Is it safe to install an app from outside Google Play?

Android warns about any app that isn't from the Play Store. Daily Streaks is signed by its developer, asks only for the vibrate permission and has no internet access. You can check that your download matches the fingerprint above.

Will my habits be backed up?

Your habits stay on your phone and aren't uploaded anywhere. To move to a new phone, use Style → Copy backup, keep the text somewhere safe, and paste it into Restore on the new phone. You can also export everything to Excel.

How do I update to a new version?

Download the new version from this page and install it over the old one. Your habits are kept.

Is there an iPhone or iPad version?

Not yet. Daily Streaks is Android only for now.

Will it come to Google Play?

That's the plan. When it does, you'll get automatic updates from the Play Store.
