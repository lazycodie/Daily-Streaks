# Daily Streaks for Android

A native Android shell (Java) that hosts the app's screens in a locked-down WebView.

- **Offline and private:** no INTERNET permission; content is served only from the APK's own assets.
- **Hardened WebView:** no JavaScript bridge, no file or content access, navigation outside the app is blocked, all web permission requests are denied.
- **Excel export** goes through Android's own "Save to..." screen (no storage permission).
- minSdk 26 (Android 8.0), targetSdk 36 (Android 16).

## Project layout
| Path | What it is |
|---|---|
| `app/src/main/java/app/dailystreaks/MainActivity.java` | The app shell |
| `app/src/main/AndroidManifest.xml` | Permissions (VIBRATE only), no backups, no cleartext traffic |
| `app/src/main/assets/www/` | The app's screens, generated by `build-web-bundle.py` |
| `app/src/main/res/` | Launcher icon (adaptive + themed), splash colours |
| `build-web-bundle.py` | Builds `assets/www/` from `../web-app/index.html`: strips cloud-sync code, adds a strict Content Security Policy and bundled fonts |

## Build
Requirements: JDK 17+, Android SDK with platform 36 and build-tools 36.

```bash
echo "sdk.dir=/path/to/Android/sdk" > local.properties
python3 build-web-bundle.py
./gradlew assembleRelease   # APK: app/build/outputs/apk/release/
./gradlew bundleRelease     # Play Store bundle: app/build/outputs/bundle/release/
```

To sign, copy `keystore.properties.example` to `keystore.properties` and point it at your keystore. Never commit the keystore or its passwords.
